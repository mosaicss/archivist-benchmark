Delta's 2025 profit sharing expense was **$1,337 million**, and employees earned **$67 million** under the Shared Rewards program in 2025.

- **Profit sharing expense:** The $1,337 million figure (down from $1,389 million in 2024) comes from the consolidated statement of operations in Delta's Q4/full-year 2025 earnings release, filed with the SEC on Form 8-K. The 10-K page cut off before its financial statements, so I couldn't read this line in the 10-K itself. It should match the 8-K, since the 10-K's audited statements usually repeat the earnings release figures. The 10-K text says Delta is paying employees about **$1.3 billion** in profit sharing in February 2026, which is the rounded amount.
- **Shared Rewards:** The 10-K says: "our employees earned $67 million under this program in 2025." The program is a monthly operational incentive.
