I couldn't open the MD&A documents themselves. The figures below come from Dollarama's quarterly earnings press releases and from news coverage that quotes them. These releases normally report the same comparable store sales numbers as the MD&A filed with them, but I haven't checked any figure against the MD&A directly.

| Quarter | Comparable store sales growth (Canada) |
|---|---|
| Q1 FY2026 (ended May 4, 2025) | **4.9%** (transactions up 3.7%, average transaction size up 1.2%) |
| Q2 FY2026 (ended Aug 3, 2025) | **4.9%** |
| Q3 FY2026 (ended Nov 2, 2025) | **6.0%** |
| Q4 FY2026 (ended Feb 1, 2026) | **1.5%** on a 13-week basis (3.5% excluding the calendar shift) |
| Q1 FY2027 | **5.6%** (transactions up 3.5%, average transaction size up 2.0%) |
| Q2 FY2027 (ended Aug 2, 2026) | **5.4%** (transactions up 3.7%, average transaction size up 1.7%) |

The prior-year comparisons in the later releases match the numbers above: Q1 FY2027's prior-year figure is 4.9%, and so is Q2 FY2027's. For Q4 FY2026, the headline figure is 1.5%; the 3.5% is the company's figure with the calendar shift taken out.

Dollarama's official press-release PDFs for Q1 and Q2 FY2027 were unreadable when I tried to open them. To confirm against the filings, check the MD&As on SEDAR+ or Dollarama's investor site.
