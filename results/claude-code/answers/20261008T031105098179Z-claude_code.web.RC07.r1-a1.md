- **Totals add up:** for rows 2, 3, 6, 7, 9–11, 13–15, 17, 19, 21, 23 and 24, the regional or ownership-type subtotals sum to the stated total. The year-over-year changes also match in rows 18, 19 and 21.
- **Year-end links:** the year-end 2021, 2022, 2023 and 2024 figures each appear as the "prior year" figure in the next 10-K's system-growth sentence.
