Here's what Union Pacific's Item 1.01 8-K (dated July 29, 2025) says about the merger agreement it signed with Norfolk Southern on July 28, 2025:

- **Cash per share:** Each Norfolk Southern share gets one Union Pacific share plus **$88.82 in cash**, without interest.
- **Fee if regulators don't approve:** If the agreement is terminated because regulatory approvals weren't obtained, Union Pacific pays Norfolk Southern a **$2.5 billion** cash termination fee.
- **End Date:** **January 28, 2028**. The filing says this date "will be automatically extended under certain circumstances." The 8-K doesn't spell out how long the extensions are.

Union Pacific filed a second 8-K the same day, which only furnishes the joint press release and investor presentation. The terms above come from the Item 1.01 filing.
