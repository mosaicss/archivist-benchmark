In Q2 2022 (the quarter ended June 30, 2022), CN reported diluted EPS of **C$1.92**. That was **up 32%** from C$1.46 in Q2 2021.

Don't mix this up with adjusted diluted EPS, which was C$1.93, up 30% from C$1.49.
