AutoZone's fiscal 2025 Form 10-K (filed October 27, 2025) gives these store counts at August 30, 2025:

- **U.S.:** 6,627 stores
- **Mexico:** 883 stores
- **Brazil:** 147 stores

That adds up to 7,657 stores. I added these up myself; the filing doesn't state the total.
